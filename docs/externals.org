* Externals

Chezmoi externals pull configuration from remote archives and refresh it with
=refreshPeriod=. Go template directives are expanded by chezmoi at apply time,
not by Org.

Tangle this file with =org-babel-tangle= after editing a block.

** Yazi

Yazi plugins and flavors have no version tags, so all archives track =master=.

*** Personal plugins

These four plugins are maintained in the chezmoi source tree, not fetched from
a remote archive:

- =confirm-quit.yazi= — ask for confirmation before quitting with multiple tabs.
- =folder-rules.yazi= — per-folder sorting rules.
- =parent-arrow.yazi= — move between parent directories.
- =smart-tab.yazi= — create a tab and enter the hovered directory.

*** Official plugins

The official plugins live in the =yazi-rs/plugins= monorepo; the template list
keeps all their entries in one place:

- =types.yazi= — type definitions for the Lua language server.
- =chmod.yazi= — change file permissions.
- =diff.yazi= — diff the selected file against the hovered one.
- =toggle-pane.yazi= — toggle, hide, and maximize panes.
- =zoom.yazi= — zoom the image in the preview pane.
- =git.yazi= — show Git status in the file list.
- =vcs-files.yazi= — filter files by Git changes.
- =mount.yazi= — mount, unmount, and eject disks.
- =full-border.yazi= — draw a full border around the UI.
- =smart-enter.yazi= — open files or enter directories with a single key.
- =smart-filter.yazi= — filter continuously, enter a unique match
  automatically, and open the file on submit.

#+begin_src toml :tangle ../home/.chezmoiexternals/yazi.toml.tmpl
{{- $yazi_plugins_base := "https://github.com/yazi-rs/plugins/archive/master.tar.gz" }}
{{- $yazi_plugins_list := list
    "types.yazi"
    "chmod.yazi"
    "diff.yazi"
    "toggle-pane.yazi"
    "zoom.yazi"
    "git.yazi"
    "vcs-files.yazi"
    "mount.yazi"
    "full-border.yazi"
    "smart-enter.yazi"
    "smart-filter.yazi"
}}

{{- range $plugin := $yazi_plugins_list }}
[".config/yazi/plugins/{{ $plugin }}"]
type = "archive"
url = {{ $yazi_plugins_base | quote }}
exact = true
stripComponents = 2
refreshPeriod = "336h"
include = ["*/{{ $plugin }}/**"]
{{- end }}
#+end_src
